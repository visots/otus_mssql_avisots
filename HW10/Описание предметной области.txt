Область:  IoT. БД для хранения информации, получаемых с устройств (датчиков). В данном примере ограничился небольшой частью сферы IoT - той где у нас есть конкретные устройства и их данные с привязкой ко времени.
Таблицы:
1. Sensors - Общее описание датчиков
2. SensorsAttributes - Дополнительные атрибуты по каждому конкретному датчику. Набор атрибутов для каждого датчика может быть разным. Атрибуты могут быть: (производитель,высота установи, координаты, ответственный, дата поверки и т.д.)
3. SensorAttributesValues - значения каждого атрибута
4. Parameters - таблица физических параметров опрашиваемых с датчиков (вес, высота, давление, температура и т.д.)
5. SеnsorParameters - таблица связи между устройствами и параметрами.
6. SensorParameterValues - таблица, содержащая в себе сами значения параметров (показателей), полученных с датчиков.
7. MeasurementUnits - таблица единиц измерения.
